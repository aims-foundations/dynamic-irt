# LMS Scraping

## Installation

* For `selenium` package:

```bash
pip install -r requirements.txt
```

* For `ChromeDriver` setup: run the script `installation.sh` by using this command:

```bash
bash installation.sh
```

* Every time the user starts a new environment or a new terminal, the user has to run this command again:

```bash
export PATH=~/chrome-headless-shell-linux64:~/chromedriver-linux64:$PATH
```
